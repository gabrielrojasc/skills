# Session title

Set the title once the PRs are resolved. Use `RV <repo>#<n>: <short PR summary>`
for one PR, or `RV <repo>#<n> +<count>` for several, so the number stays visible
in a narrow title. Add the owner only when it isn't `riskive`. Shorten long
repository names the way the team does, such as `ep-api` for
`executive-protection-api`, `go-ep` for `go-executive-protection`, and `ds-sdk`
for `datasource-sdk`.
