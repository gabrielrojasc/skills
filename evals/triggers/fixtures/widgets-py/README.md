# WIDGETS!!!

this is widgets. it makes widgets. In order to use it you will want to first install it (see below) and then you can just simply run widgets init and it should hopefully work!!

INSTALL
pip install -e .   (or use the test extra if you want the tests too i think)

## Usage:
- widgets init  - Creates The Config
- there is also a --template option, default is basic, it can be other things too
